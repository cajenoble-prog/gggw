# Equipment and Packing Checklist

Only bring items permitted in writing by Memorial Park.

## Documents and check-in

- [ ] Reservation and approval copies
- [ ] Insurance certificate/waivers, if required
- [ ] Final event-day roster, printed from [check-in-roster.pdf](check-in-roster.pdf); editable source: [check-in-roster.html](check-in-roster.html)
- [ ] Blank walk-up record, if allowed
- [ ] People and sighthound tally sheet
- [ ] Printed route maps
- [ ] Emergency contacts
- [ ] Incident forms
- [ ] Clipboards and pens
- [ ] Name tags or volunteer identifiers

## GPA Houston station

- [ ] Approved GPA Houston banner/sign
- [ ] Adoption/foster/volunteer materials
- [ ] Approved donation QR sign, if permitted
- [ ] Table covering and clips
- [ ] One approved extra table, if needed
- [ ] Approved weighted canopy, if needed
- [ ] Chairs, if approved/needed

## Safety and comfort

- [ ] Human first-aid kit
- [ ] Canine first-aid kit
- [ ] Emergency water
- [ ] Individual/disposable dog-water containers
- [ ] Cooling towels
- [ ] Ice/cooler for emergency use
- [ ] Sunscreen
- [ ] Insect repellent
- [ ] Hand sanitizer
- [ ] Charged phones
- [ ] Power bank and cables
- [ ] High-visibility volunteer identifiers

## Cleanup

- [ ] Dog-waste bags
- [ ] Trash bags
- [ ] Paper towels
- [ ] Disposable gloves
- [ ] Litter grabber, if available
- [ ] Approved tape/temporary sign supports

## Signs

- [ ] Check-in
- [ ] GPA Houston information
- [ ] Food-free dog zone
- [ ] Please give dogs space
- [ ] Secure all food
- [ ] Full-route turnaround
- [ ] Short-route turnaround
- [ ] Trash/recycling

## Do not pack unless explicitly approved

- [ ] Amplified speaker
- [ ] Generator
- [ ] Grill, propane or open flame
- [ ] Merchandise for sale
- [ ] Shared food or beverages
- [ ] Decorations attached to park property
- [ ] Glass or alcohol
