## Working rules

1. Record every commitment in `action-tracker.md` with one owner and due date.
2. Record approvals and material choices in `contacts-decisions.md`.
3. Do not publish the exact location until Memorial Park provides written approval.
4. Count people and sighthounds separately; the 50-person cap includes volunteers.
5. Treat any item marked **Pending confirmation** as unapproved.
6. Avoid storing medical details or unnecessary personal data in this workspace.

## Current critical path

1. Obtain GPA Houston authorization and event lead contact.
2. Reserve an appropriate Memorial Park pavilion or picnic area.
3. Obtain written approval for the organized walk, dogs, information station and BYO picnic.
4. Confirm insurance, permit and waiver requirements.
5. Scout and approve a short route.
6. Register the walk with GGGW.
7. Open capped registration and recruit volunteers.

## Review PDFs

From the repository root, run `npm install` once and then `npm run render:pdf` whenever review copies are needed. The script recreates `review-pdfs/`, preserves the source directory structure, and renders every project Markdown file as a letter-size PDF. Generated PDFs are excluded from version control.
